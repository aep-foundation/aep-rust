# Contributing

Contributions are welcome through GitHub issues and pull requests.

Before opening a pull request:

1. Confirm protocol behavior against `aep-foundation/aep-specs`.
2. Keep public APIs idiomatic, minimal, and supported by tests.
3. Run `make verify`.
4. Update integration documentation when caller-visible behavior changes.

Use focused commits and describe current behavior rather than its history. Security reports must
follow [SECURITY.md](./SECURITY.md). Community participation is governed by the
[AEP Code of Conduct](https://github.com/aep-foundation/.github/blob/main/CODE_OF_CONDUCT.md).
